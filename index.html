Encomendas guardadas▸

As encomendas ficam guardadas neste navegador/dispositivo. Exporte periodicamente para ter uma cópia de segurança ou para levar para outro PC/telemóvel.

⚙ Armazenamento central (opcional)▸

Liga esta app a um projeto Supabase gratuito para as encomendas ficarem visíveis em qualquer PC ou telemóvel automaticamente, sem exportar/importar.

Como criar o projeto (uma vez, grátis)▸
  1. Cria conta grátis em supabase.com e um novo projeto (demora ~2 min a ficar pronto).
  2. No menu lateral, abre o SQL Editor e corre o código abaixo para criar a tabela de encomendas.
  3. Vai a Project Settings → API, copia o Project URL e a anon public key e cola-os aqui em cima.
create table orders (
  id text primary key,
  client text,
  order_name text,
  created_at timestamptz default now(),
  mode text,
  dxf_file_name text,
  dxf_text text,
  manual jsonb,
  material_id text,
  material_snapshot jsonb,
  quantity int,
  machine_snapshot jsonb,
  cost_snapshot jsonb
);

alter table orders enable row level security;

create policy "public access"
  on orders for all
  using (true) with check (true);

Esta política deixa a tabela acessível a quem tiver o link e a chave (que ficam visíveis no código da página). Adequado para uso interno da empresa, não para dados sensíveis ou públicos. Se um dia precisar de mais segurança (autenticação por utilizador), avise-me.

A ficha do operador não mostra preços. A ficha interna inclui a decomposição de custos.

Ferramenta de cálculo interno. As velocidades de corte, preços de material e custo/hora são valores de referência editáveis — ajuste-os à realidade da sua máquina e fornecedores antes de orçamentar. A área de material calculada com base no retângulo envolvente é uma aproximação à ocupação de chapa; para peças aninhadas em conjunto, o consumo real de chapa pode ser inferior.
