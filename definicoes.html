Armazenamento central ▸

Liga esta app a um projeto Supabase gratuito para as encomendas ficarem visíveis em qualquer PC ou telemóvel automaticamente, sem exportar/importar.

Como criar o projeto (uma vez, grátis)▸
  1. Cria conta grátis em supabase.com e um novo projeto (demora ~2 min a ficar pronto).
  2. No menu lateral, abre o SQL Editor e corre o código abaixo para criar a tabela de encomendas.
  3. Vai a Project Settings → API, copia o Project URL e a anon public key e cola-os aqui em cima.
create table orders (
  id text primary key,
  client text,
  order_name text,
  order_number text,
  created_at timestamptz default now(),
  mode text,
  dxf_file_name text,
  dxf_text text,
  manual jsonb,
  material_id text,
  material_snapshot jsonb,
  quantity int,
  machine_snapshot jsonb,
  cost_snapshot jsonb
);

alter table orders enable row level security;

create policy "public access"
  on orders for all
  using (true) with check (true);

Esta política deixa a tabela acessível a quem tiver o link e a chave (que ficam visíveis no código da página). Adequado para uso interno da empresa, não para dados sensíveis ou públicos. Se um dia precisar de mais segurança (autenticação por utilizador), avise-me.

Se já tinha a tabela criada antes desta atualização, corra também: alter table orders add column if not exists order_number text;

Guardar também numa pasta do computador (opcional)▸

O teu navegador não suporta esta funcionalidade — funciona apenas no Chrome ou Edge, no computador (não em Safari, Firefox ou telemóveis).

Escolhe uma pasta no computador. Sempre que guardares uma encomenda (na página de Orçamentação), a app cria lá dentro uma subpasta com o nome do cliente e grava o ficheiro DXF (se houver) mais um resumo em .txt com os dados e custos.

Precisão das estimativas (tempo real vs estimado)▸

Compara, por material e espessura, o tempo de corte que a app estimava com o tempo real que foste registando nas encomendas Final — ajuda a perceberes onde as velocidades da tabela precisam de ajuste.

Para orçamentar ou guardar uma encomenda, vá a Orçamentação.
